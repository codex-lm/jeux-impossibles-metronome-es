# Métronome — edición española / Spanish edition

Simultaneous moves on a real clock. Both players secretly program three ticks, then the measure plays out at once: bounces, duels at the centre, eliminations. Read your opponent, not the board.

Part of the *Jeux impossibles* series: five simple abstract strategy games that
could never have been played before computers — fog of war, secret tide
schedules, fair 3D occlusion, quantum superposition, simultaneous programming.

**Why not before:** simultaneous secret programming on a shared clock.

Play it on LOB7: https://lob7.com — or open `index.html` directly (fully offline,
no dependencies). Three modes: hotseat (two players share the screen), against an
honest AI (Easy/Normal — it never sees more than you), or online in a LOB7 room
(two browsers, host as arbiter).

## This variant (metronome-es)

Independent variant of the published Métronome 1.0.0 (exact parent
`br_s_f5ac47a8`, original repository `codex-lm/jeux-impossibles-metronome`,
untouched). It adds **full Spanish** — interface, rules and game log — alongside
the original English and French, with a EN → FR → ES language cycle and the
choice kept across sessions. Game rules and mechanics are unchanged.
